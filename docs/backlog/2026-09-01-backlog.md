## A2: Reject line ranges that slice to an empty excerpt (past EOF, lo>hi, lo<=0)

Priority: Urgent | Labels: trust,0.3.2 | Status: Verified

Claim: `_slice` silently returns "" for ranges past EOF, lo>hi, or lo<=0. The anchor then hashes the empty string, `verify_excerpt` returns True against ANY file, and such a fact can never drift. A typo in line numbers creates a permanently verified fact.
Where: src/cartographer/anchor.py `_slice`, `make_code_anchor`, `verify_excerpt`; lint in map_loader.py.
Expected: `_slice` raises ValueError when lo<1, hi<lo, or hi>len(body); `make_code_anchor` propagates it; `verify_excerpt` returns False on it; lint rejects lines with lo<1 or hi<lo. Also treat an empty-string excerpt hash as a lint problem.
Verified 2026-09-01: docs/backlog/repro/A2.py ((5,9),(3,1),(0,0),(0,2),(-1,1) all slice to ""; check exits 0 after rewrite for (3,1) and (0,0); past-EOF stays vacuous while the file is shorter than lo).
Acceptance: A2.py shows ValueError/False; new test `test_anchor_past_eof_never_verifies`.

## A3: Server reports a fact clean after its local file disappears mid-session

Priority: Urgent | Labels: trust,0.3.2 | Status: Verified

Where: src/cartographer/mcp_server.py `_split` else-branch; src/cartographer/remote.py `fact_status`.
Expected: server and CLI always agree. Distinguish locally-verified "ok" from remote "ok" in the snapshot (e.g. OK_LOCAL, or omit local results from the snapshot). When the file is absent, only a remote OK counts as clean; otherwise fall to the same DRIFTED/UNVERIFIABLE rule `fact_status` uses. Factor that tail into one shared helper.
Verified 2026-09-01: docs/backlog/repro/A3.py.
Acceptance: A3.py shows staleness_check DRIFTED/UNVERIFIABLE matching check; new test `test_server_and_cli_agree_after_file_removed`.

## C1: cartographer anchor <path> --lines A-B subcommand

Priority: High | Labels: feature | Status: Proposed

Prints the anchor JSON for a file and line range, defaulting revision to `git -C <service> rev-parse --short HEAD` and date to today. Replaces the python -c recipe in CLAUDE.md, works with pipx/uv tool installs, and is the single biggest curation-loop improvement. Consider `cartographer add --approved-by <name>` that appends a lint-checked fact (still human-gated).

Priority: Medium | Labels: feature | Status: Proposed

Structured output (per fact: identity, anchor, state ok/drifted/unverifiable) plus a documented schema next to the exit codes. Lets the drift workflow and other tooling consume results.
